### Ключевые задачи для каждой системы

#### Сервис управления депозитами
- Разработка централизованного хранилища ставок
- Создание API для доступа к ставкам
- Разработка модуля экспорта и форматирования файлов
- Реализация механизма безопасной передачи файлов
- Внедрение системы мониторинга и уведомлений

#### Система кол-центра банка
- Доработка API для интеграции с Сервисом управления депозитами
- Модификация БД для хранения информации о ставках
- Обновление UI для отображения актуальных ставок операторам
- Настройка регулярного обновления данных о ставках

#### Система партнерского кол-центра
- Настройка SFTP-сервера для приема файлов
- Разработка процедуры импорта данных из файлов
- Обновление интерфейса для отображения ставок операторам
- Настройка процедур мониторинга обновлений ставок
