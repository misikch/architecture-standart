| P1     | Время отклика по всем операциям < 100 мс                                          | Важно для положительного пользовательского опыта |
| P2     | Оптимизация загрузки справочных данных                                            | Сейчас занимает больше секунды                   |
| P3     | Горизонтальное масштабирование и балансировка нагрузки                            |                                                  |

| S3     | Разработка документации для дальнейшего расширения                                |                                                  |
| S4     | Возможность перехода на микросервисную архитектуру для депозитного модуля         | Архитектурное решение для дальнейшего развития   |
| S5     | Внедрение мониторинга производительности и доступности                            | Контроль соответсвия требованиям                 |
